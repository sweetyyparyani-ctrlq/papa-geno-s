# 🍕 Papa Geno's – Luxury Pizzeria & Gourmet Grill

> **A premium, modern, and responsive restaurant website crafted with rich chocolate brown, warm ivory cream, and crimson red tones.**

---

## 🌟 Overview

**Papa Geno's** is a high-end restaurant web application that showcases handcrafted stone-hearth pizzas, gourmet smash and zinger burgers, authentic flame-grilled rolls, chicken wings, creamy pastas, and crispy appetizers with realistic Pakistani Rupee (PKR - Rs.) pricing and mouth-watering imagery.

---

## ✨ Features

- **🎨 Luxury Aesthetic**: Designed with deep chocolate browns (`#120905`, `#26140b`), warm ivory cream (`#fdf8f0`, `#f5e9d6`), and rich crimson red accents (`#c92a2a`, `#e03131`) with brushed gold trim.
- **🏰 Grand Entrance Spotlight**: Showcases Papa Geno's illuminated grand veranda and ambient dining hall.
- **🍕 Comprehensive Menu with PKR Pricing**:
  - **Artisan Pizzas**: Tikka Pizza, Kababish Pizza, Shahi Pizza, Bihari Pizza (with Small, Medium, and Large size selectors).
  - **Gourmet Burgers**: Double-crunch Zinger Burger, Peshawari Chapli Burger.
  - **Rolls & Wraps**: Charcoal Chicken Roll, Authentic Lebanese Shawarma, Grilled Tortilla Wrap.
  - **Wings & Sides**: Honey BBQ / Buffalo Chicken Wings, Crispy Golden French Fries, Fiery Hot Shots.
  - **Pasta**: Creamy Chicken Alfredo Penne Pasta.
  - **Signature Deals**: Midnight Craving Box, Duo Pizza Fiesta, Royal Emperor Feast.
- **🛒 Functional Shopping Cart**:
  - Slide-out drawer with smooth animations.
  - Increment, decrement, and remove items.
  - Persistent order state saved in `localStorage`.
  - Promo code support: `PAPA10` for 10% off, `GENO50` for Rs. 50 off.
  - Free delivery threshold calculation (orders over Rs. 1,999).
- **💳 Multi-step Checkout & Order Desk**:
  - Customer contact details, delivery address, and area selector.
  - Delivery vs. Self-Pickup toggle.
  - Payment methods: Cash on Delivery (COD), JazzCash / Easypaisa, Card on Delivery.
  - Instant **WhatsApp Order Link** generator with formatted receipt for one-click ordering.
  - Digital printable receipt with unique Order ID (e.g., `#PG-784291`).
- **📅 Table Reservation Modal**: Reserve VIP booths or veranda seating for celebrations and dinners.
- **📱 100% Responsive**: Seamlessly optimized for smartphones, tablets, laptops, and ultra-wide desktops.

---

## 🛠️ Built With

- **HTML5**: Semantic tags, accessible ARIA attributes, modal dialogs.
- **CSS3**: Custom properties, glassmorphism backdrop filters, responsive grid & flexbox, smooth cubic-bezier transitions.
- **JavaScript (ES6+)**: Modular client-side state management, search filter, cart drawer, receipt generator.
- **Google Fonts**: *Cinzel*, *Playfair Display*, and *Plus Jakarta Sans*.
- **FontAwesome 6**: Rich icon set.
